# Report structure and text budgets

Text budgets are hard limits. The first version of the example was rejected as
"too much text"; the accepted version roughly cut it by two-thirds.

## 1 · Overview
- **Framework cards** (3): pillar name, ≤10-word definition, maturity meter
  (Table stakes / Emerging / Frontier). Each links to its pillar in chapter 2.
- **Short answers** (one per user question): ≤10-word answer + one link.
- **Evidence**: one bar chart of the strongest metric source, plus 3 quote
  tiles (≤15 words each, with source).
- **Capability grid**: products × pillars, grouped by category. The section
  headline states the takeaway ("Docs tools understand. Code and data tools learn.").

## 2 · Competitive landscape (facts only)
- Intro heatmap: scope rows × pillars, cell = number of products.
- Segmented control: one sub-view per pillar + one "lens" view for the user's
  special domain.
- Per pillar:
  - Kicker, ≤8-word headline, maturity meter, "N products · N screenshots".
  - 3 CUJs, each ≤12 words, in the user's voice.
  - Per pattern: number + scope + which CUJ it serves, title, then "who"
    rows (product name + ≤14-word fact + source link), then the screenshot gallery.
- Lens view: ≤20-word framing, 3 big numbers ("0 of 6 …"), loop-coverage matrix.
- No design notes, no "should", no "opportunity" in this chapter.

## 3 · Principles & explorations (interpretation)
- Principles: 3 columns (one per pillar), 4 items each, a 2–3 word title + ≤8-word line.
- Framework diagram: the loop ring + ≤30 words.
- Explorations: one HTML sketch per pattern, each card = "builds on X, Y" + ≤7-word title.
  Mark sketches as yours; they are discussion starters, not specs.
- Opportunities: one row each, pillar tag, ≤7-word problem, "Try:" ≤12 words.
  Flag the largest one.

## 4 · Open questions
- 6 decision questions, each a ≤12-word headline + ≤12-word reason.
- "Not yet verified": every gap you hit (missing screenshots, unconfirmed scope,
  no usage data).

## 5 · Sources
- Grouped by pillar; every link used anywhere on the page.
- Credit line: screenshots belong to their companies; press and video frames labelled.

## Voice
Plain, specific, active. Name things the way users do. No em-dash asides,
no "not X but Y", no stock phrases. Quote real numbers with their source and year.
